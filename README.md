## 产品功能

招生预算、获客成本、转化成本和盈亏平衡测算。

- 主要输入：渠道报价、预计线索量、到访率、成交率、客单价、人员成本和活动固定成本
- 主要输出：预算明细、获客成本、转化成本、盈亏平衡点、敏感性分析和假设表
